## How to Run

### Option 1: Google Colab (recommended)
1. Open the practical folder in this repo
2. Click the `.ipynb` file
3. Click the **Open in Colab** badge, or use this link format:
   `https://colab.research.google.com/github/yogita-create/Machine-Learning-/blob/main/practical2/ML2.ipynb`
4. Click **Runtime → Run all**

### Option 2: Run locally
```bash
# Clone the repo
git clone https://github.com/yogita-create/Machine-Learning-.git
cd Machine-Learning-

# Install the libraries
pip install numpy pandas matplotlib scikit-learn jupyter

# Start Jupyter
jupyter notebook
```
Then open the notebook you want.
